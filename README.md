# 7 天 LLM 应用入门

> 给前端开发者的 LLM 应用互动教程：7 天，从第一次调用 API，到做出可上线的 AI 聊天应用。

🌐 **在线阅读**：https://ai-interview-tutorial-kggr.vercel.app

## 适合谁

- 有 Vue / React / TypeScript 基础，想转向 AI 应用开发的前端开发者
- 调用过 LLM API，但还没做出过完整应用的人

## 内容结构

- **上篇 · 建立认知**：从业务前端到 AI 应用工程师的全景、你要成为怎样的 AI 前端、Merrill 五条原则补课清单、一周路线图
- **Day 1 · 跑通链路**：底层概念（模型到底在做什么）、准备环境、第一次调用——先证明链路通了
- **Day 2–4 · 做出应用**：把流接进 React、多轮对话与基本体验、Function Calling（让模型学会"请求工具"）
- **Day 7 · 验收**：按作品标准验收一个可上线的聊天应用
- **番外**：FDE 方向（AI 落地的最后一公里）、面试备战（74 道题按学习阶段消化）、前辈翻车实录（3 个真实转型/落地故事：34 岁后端裸辞踩坑一年、Go 后端 3 个月 28k→45k、Agent 落地实施论）、岗位扫描（杭州+西安 385 个在招 AI 岗，城市/方向/关键词筛选，48h 自动刷新）
